# Tus vídeos

> Your videos are saved here, one folder per video. git ignores everything in this folder except this file.

Aquí se guarda cada vídeo que haces con youtubeman, en su propia carpeta (por ejemplo `videos/MiApp/`): el material
(`kit/`), las escenas y los vídeos terminados (`salida/`).

git ignora todo lo que hay aquí salvo este archivo: tus vídeos nunca se suben al repo.
